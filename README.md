# Thuy Le

An Among Us-inspired portfolio. Static HTML, CSS, and JavaScript with no runtime dependencies. Vercel builds `dist/` when `main` changes.

## Local development

Use Node.js 22 or newer. From the repository folder:

```sh
npm run check
npm run build
python3 -m http.server 3000 --directory dist
```

Open http://localhost:3000. After changes have been pushed through ChatGPT, run `git pull --ff-only` to update your local copy. Commit or stash any local edits first.

## Editing

- `dist/data.js`: resume entries, projects, and skills.
- `dist/render.js`: section and detail markup.
- `dist/index.html`: the page shell and introduction. Crewmate and portfolio marker blocks are generated by `npm run build`; edit their source modules instead.
- `dist/styles.css`: layout, colors, lettering, responsive styles, and animation.
- `dist/app.js`: customization, dialogs, keyboard navigation, sound, and wiring task.
- `dist/crewmate.js`: the crewmate and hat SVG artwork.
- `dist/assets/` and `dist/Thuy-Le-Resume.pdf`: portrait, fonts, favicon, and resume.

Design preferences: dark ship panels and black windows, mint game controls, large readable text, minimal labels. The default crewmate is red with a suit and duck hat. Only crewmate speech is lowercase; preserve the capitalization of resume content. Respect the visitor's reduced-motion preference. Fonts are served locally under the licenses in `dist/assets/fonts/`.
